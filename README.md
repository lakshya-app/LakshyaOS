# LakshyaOS

Responsive CBSE/JEE/NEET/CUET study planner and focus dashboard.

## Features

- Responsive mobile, tablet and desktop layout
- Dashboard with syllabus completion and exam countdowns
- Smart study scheduler
- Syllabus search, filtering and progress tracking
- Pomodoro focus timer and Focus Mode
- Revision queue and chapter scratchpad
- NCERT/CBSE resource hub and split reader
- Local PDF loading
- Custom resource links
- JSON backup/restore
- CSV study-plan export
- ICS calendar export
- Dark mode
- Command palette
- LocalStorage persistence
- Progressive Web App support
